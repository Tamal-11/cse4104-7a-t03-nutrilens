# AI Model

This folder contains the AI food recognition model code.

## Goal

Train a CNN model using TensorFlow / Keras and OpenCV to identify food from images.

## Main Tasks

1. Collect or use a food image dataset.
2. Preprocess food images.
3. Train CNN model.
4. Evaluate model accuracy.
5. Save trained model.
6. Use model for prediction from uploaded images.

## Commands

```bash
pip install -r requirements.txt
python src/train.py
python src/predict.py
```
